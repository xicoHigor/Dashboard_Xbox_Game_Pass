# Dashboard_Xbox_Game_Pass
Este projeto apresenta um dashboard interativo para análise de dados relacionados às assinaturas de serviços e passes de jogos, com foco no Xbox Game Pass, EA Play e Minecraft Season Pass.

O objetivo é transformar dados em informações visuais que facilitem a compreensão dos valores das assinaturas, a comparação entre categorias e a análise dos resultados conforme o tipo de plano selecionado.

O projeto faz parte da minha jornada de aprendizado em Análise de Dados, aplicando conceitos de organização, visualização e interpretação de informações para apoiar a tomada de decisões.

Objetivos

Analisar os valores associados às assinaturas de jogos.

Comparar indicadores entre diferentes serviços.

Visualizar os resultados por meio de gráficos e cartões de indicadores.

Utilizar filtros para explorar diferentes tipos de assinatura.

Desenvolver habilidades práticas em análise e visualização de dados.

🛠️ Funcionalidades

Indicadores financeiros: exibição de valores totais associados aos passes e serviços analisados.

Filtros interativos: seleção por periodicidade de assinatura, incluindo planos anuais, mensais e trimestrais.

Gráficos comparativos: visualização dos valores de acordo com as categorias apresentadas no painel.

Análise de indicadores: comparação entre respostas afirmativas e negativas de um dos campos da base de dados.

Interface visual: organização dos indicadores em um painel de fácil leitura.

 Principais indicadores

O dashboard apresenta indicadores relacionados a:

Total de assinaturas do EA Play.

Total de assinaturas do Minecraft Season Pass.

Valores associados ao Xbox Game Pass.

Comparação dos resultados conforme os filtros selecionados.

Os números exibidos são ilustrativos dos dados apresentados no painel e podem variar conforme os filtros aplicados.
